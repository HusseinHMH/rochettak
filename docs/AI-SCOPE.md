# AI Scope and Guardrails

## AI-enabled product vision from the roadmap
1. Patient and doctor support chatbot for booking guidance and platform education.
2. WhatsApp support bot for onboarding and common workflow questions.
3. Clinician productivity: voice-to-text visit notes, structured summaries and document organization.
4. OCR extraction from uploaded prescriptions and medical documents.
5. Operational assistance: availability checks, workflow suggestions and non-clinical administrative insights.
6. Prescription workflow assistance as a clinician-controlled concept, never autonomous medical decision-making.

## What this demo actually does
- Scripted conversational assistant for platform workflows.
- Sample OCR extraction output using fictional text.
- UI patterns showing where note structuring and documentation support would fit.
- No external LLM, speech recognition, OCR engine or medical database is connected.

## Safety constraints
- No diagnosis, triage, treatment recommendation, medication selection or dosage calculation.
- No autonomous prescription generation or approval.
- Any future AI support embedded in clinical workflows must be clinician-reviewed and auditable.
- Never use real patient data in this public demo.
- Production deployment requires secure backend processing, access control, encryption, retention policy, audit logs, vendor review, legal/privacy assessment and clinical safety validation.
