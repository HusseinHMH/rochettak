# Rochtetak Demo Guide

## Suggested sales demonstration (10–15 minutes)

1. **Start in Doctor workspace** — show the operational dashboard and today's appointment flow.
2. **Open Patient Directory** — search and open a synthetic patient file. Explain that each profile can link visits, documents, prescriptions, lab results and payer details.
3. **Open Calendar** — demonstrate the shared scheduling concept across doctors, clinics, departments, labs and imaging.
4. **Switch to Hospital Management** — show the multi-facility command center and 12 clinical / operational departments.
5. **Open Departments** — show staffing, department-head ownership and capacity indicators.
6. **Open Document Intelligence** — select a local sample file or load the sample OCR output. Explain the intended intake → extraction → human review → patient record journey. The OCR is simulated in this prototype.
7. **Open Laboratory** — show the regional starter catalog and sample-order workflow. Test catalog entries, pricing, specimens and turnaround times are examples and must be configured by each lab.
8. **Switch to Department Head** — show the department command center and its team / operational controls.
9. **Customize Dashboard** — hide, add and reorder widgets, then restore the default layout.
10. **Switch to Patient Portal / Pharmacy / Insurance** — demonstrate the connected ecosystem and handoff concepts.

## Dataset inventory

All data is synthetic and generated in the browser:
- 650 patient profiles
- 85 doctor profiles
- 12 departments
- 3,500 appointment records
- 1,200 document index records
- 2,100 laboratory orders
- 185 insurance claims
- 340 pharmacy orders
- 24 illustrative facilities in the enterprise dashboard

These figures represent the size of the demo dataset, not real customers, users, transactions, adoption, revenue or traction.

## Regional considerations

- Arabic and English UI, RTL and LTR layouts
- Egyptian market sample cities and EGP display
- Configurable patient identifiers, contact details and facility-specific workflows
- WhatsApp / SMS communication concepts
- Paper-first document intake and Arabic / English document classification concepts
- Local lab test catalogue starter set, with configurable specimen, price and turnaround fields

The catalogue is a product-demo starter list, not a clinical standard or a definitive national catalogue. Reference ranges, units, sample handling, test names and prices must be verified and configured by the operating laboratory.

## What is simulated

The prototype uses local browser state and synthetic content. It does not provide:
- Real OCR, handwriting recognition, LLM or speech recognition
- Real medical diagnosis, drug selection, dosage calculation or treatment recommendations
- Production authentication, access controls, multi-tenant isolation or audit services
- Real booking, WhatsApp, SMS, payment, pharmacy, lab, radiology or insurance integrations
- Persistent database storage or real file upload to a server

Never enter real patient information into this prototype.
